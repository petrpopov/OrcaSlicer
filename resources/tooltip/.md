# OrcaSlicer PE v2.3.2-pe.6

## Quick start

1. Install `Bambu Connect` and launch it.
2. Install `OrcaSlicer PE`.
3. On macOS, remove quarantine after copying the app to `/Applications`:

```bash
xattr -dr com.apple.quarantine "/Applications/OrcaSlicerPE.app"
```

4. In `Preferences`, enable `Use Bambu Lab Connect`.
5. Slice your model and click `BBL Connect` in the send dialog.

## Highlights

- Bambu Connect handoff now uses the project name.
- The send dialog closes after Bambu Connect starts successfully.
- XYZ Calibration Cube was added to handy models.
- Update checks now use the GitHub Releases API.
- OpenGL compatibility was improved for core and ES profiles.
- The release also includes fresh upstream OrcaSlicer fixes.
