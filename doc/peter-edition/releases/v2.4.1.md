# OrcaSlicer PE v2.4.1

`v2.4.1` syncs the Peter's Edition fork with upstream OrcaSlicer 2.4.1 while preserving the fork-specific workflow and UI changes.

## Highlights

- Upstream OrcaSlicer changes through the 2.4.1 line.
- BBL Connect handoff integration remains available for Bambu Lab workflows.
- Peter's Edition branding, bundle naming, and release packaging remain in place.
- Fork-specific UI polish, dynamic accent color support, filament dropdown/search improvements, and handy-model additions are preserved.
- Build/release workflow customizations for this fork are retained.

## Notes

- The app-visible version is `2.4.1`.
- macOS app bundle remains `OrcaSlicerPE.app`.
- GitHub releases for this fork are published at https://github.com/petrpopov/OrcaSlicer/releases.
