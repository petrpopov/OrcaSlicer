# OrcaSlicer PE v2.3.2-pe.6

## RU

### Короткая инструкция по установке

1. Скачайте подходящий артефакт релиза для вашей ОС.
2. Установите `Bambu Connect` из официальных источников Bambu Lab и запустите его:
   - [Bambu Connect wiki](https://wiki.bambulab.com/en/software/bambu-connect)
   - [Bambu Lab announcement](https://blog.bambulab.com/updates-and-third-party-integration-with-bambu-connect/)
3. Установите `OrcaSlicer PE`.
4. На macOS после копирования `OrcaSlicerPE.app` в `/Applications` выполните:

```bash
xattr -dr com.apple.quarantine "/Applications/OrcaSlicerPE.app"
```

5. В `Preferences` включите `Use Bambu Lab Connect`.
6. Откройте проект, выполните `Slice plate`, затем в диалоге отправки нажмите `BBL Connect`.

Подробная инструкция:

### О релизе

`v2.3.2-pe.6` — это релиз для пользователей, которым нужен актуальный OrcaSlicer с сохранённым и доведённым до рабочего состояния сценарием печати на принтерах Bambu Lab через `Bambu Connect`.

Если вы видите этот форк впервые, суть простая: это не альтернативный слайсер "с нуля", а практичный форк OrcaSlicer с точечными изменениями вокруг handoff в `Bambu Connect`, UX печати, совместимости и сопровождения релизов.

### Что нового именно в v2.3.2-pe.6

- передача задания в `Bambu Connect` теперь использует имя проекта, а не временное имя файла;
- диалог отправки закрывается автоматически после успешного запуска `Bambu Connect`;
- добавлена модель `XYZ Calibration Cube` в handy models;
- исправлены assert-проблемы при импорте и при выходе приложения в debug-сборках;
- обновления приложения переведены на проверку через GitHub Releases API;
- добавлены защитные правки для legacy OpenGL-вызовов в core/ES-профилях;
- синхронизированы определения placeholder-переменных custom G-code с runtime;
- исправлено имя macOS bundle в release-сборке;
- в релиз также вошла свежая синхронизация с upstream OrcaSlicer, включая накопленные исправления движка, UI, переводов, профилей и Linux/Flatpak-инфраструктуры.

### Что добавлено в форк с самого начала

- интеграция `Bambu Connect` прямо из окна отправки на печать;
- переключатель `Use Bambu Lab Connect` в настройках;
- возврат Bambu-подобного масштаба preview-слайдеров;
- единый accent color для native UI и встроенного web UI;
- отдельная секция `Peter's Settings` для настроек форка;
- улучшенный сценарий просмотра, фильтрации, редактирования и удаления кастомных филаментов;
- предзагрузка AMS-списков для более быстрого выбора материалов;
- корректная тема и accent color в диалоге flushing volumes;
- быстрый поиск в списке материалов, включая исправления backspace, раскладок клавиатуры и корректного сброса фильтра;
- брендинг Peter's Edition в splash/about;
- сохранение стабильной сборки и доставки артефактов для macOS, Windows и Linux;
- регулярная синхронизация с upstream OrcaSlicer, чтобы форк не застывал на одном состоянии.

### Как работать после установки

1. Установите и запустите `Bambu Connect`.
2. Запустите `OrcaSlicer PE`.
3. Включите `Use Bambu Lab Connect`.
4. Подготовьте модель и нажмите `Slice plate`.
5. В окне отправки нажмите `BBL Connect`.
6. Дальше подтвердите отправку уже через `Bambu Connect`.

### About this release

`v2.3.2-pe.6` is aimed at users who want a current OrcaSlicer build while keeping a working and maintained `Bambu Connect` workflow for Bambu Lab printers.

If this is your first time seeing the fork, the core idea is simple: this is not a separate slicer rewritten from scratch. It is a pragmatic OrcaSlicer fork with focused changes around `Bambu Connect` handoff, print UX, compatibility, and release maintenance.

### What is new in v2.3.2-pe.6

- `Bambu Connect` handoff now uses the project name instead of a temporary filename;
- the send dialog now closes automatically after `Bambu Connect` starts successfully;
- `XYZ Calibration Cube` was added to handy models;
- assert issues on import and application shutdown were fixed in debug builds;
- app update checks now use the GitHub Releases API;
- legacy OpenGL texture/color calls are now guarded for core and ES profiles;
- custom G-code placeholder definitions were synced with runtime variables;
- the macOS release bundle naming was fixed;
- the release also includes a fresh upstream OrcaSlicer sync with accumulated engine, UI, translation, profile, and Linux/Flatpak fixes.

### What the fork has added since day one

- direct `Bambu Connect` integration in the send-to-printer dialog;
- the `Use Bambu Lab Connect` preference switch;
- restored Bambu-like preview slider sizing;
- a unified accent color across native UI and embedded web UI;
- a dedicated `Peter's Settings` section for fork-specific preferences;
- a better flow for browsing, filtering, editing, and deleting custom filaments;
- AMS list prefetch for faster filament selection;
- correct theme/accent usage in the flushing volumes dialog;
- fast filament list search, including fixes for backspace handling, keyboard layouts, and proper filter reset;
- Peter's Edition branding in the splash screen and about dialog;
- stable build and artifact delivery for macOS, Windows, and Linux;
- regular upstream OrcaSlicer syncs so the fork does not stall on an old base.

### How to use it after installation

1. Install and launch `Bambu Connect`.
2. Launch `OrcaSlicer PE`.
3. Enable `Use Bambu Lab Connect`.
4. Prepare your model and click `Slice plate`.
5. Click `BBL Connect` in the send dialog.
6. Confirm the send operation in `Bambu Connect`.
